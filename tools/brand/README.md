# Packaged brand assets

The website at `https://panel-assistant.io/brand/` owns the brand artwork. Run `node tools/brand/sync.mjs sync` to download the published assets and regenerate the frontend's embedded mark and outlined name. The manifest records each source URL, packaged path and SHA-256. The name is extracted from the canonical wordmark; PNG icons are copied without re-encoding.

Run `node tools/brand/sync.mjs check` to compare packaged and generated bytes with the latest published website. CI runs this check and fails when website artwork changes. `check --offline` checks packaged hashes and generated output without network access, and runs before frontend builds. README imagery uses the website URLs directly.
